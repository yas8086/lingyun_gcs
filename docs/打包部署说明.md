# 灵云01 地面站 · 打包部署说明（决策 #35 / #36）

> 面向地面站 Qt 桌面端的**发布打包与目标机部署**。
> 对应《落地开发决策清单》第九节：
> - **#35 打包工具**：按目标机 OS 选择 `windeployqt`（Windows）/ `linuxdeployqt`（Linux）
> - **#36 目标运行机**：确认机型（PC / 树莓派）后再定
>
> 本文档给出可直接执行的构建、打包、部署步骤与目标机要求。

## 1. 目标运行机（决策 #36）

### 1.1 推荐机型
地面站与机载（树莓派5）通过**串口数传**连接，属本地操作台，推荐运行在 **PC** 上：

| 场景 | 目标机 | 系统 | 说明 |
|------|--------|------|------|
| **主推（推荐）** | x86_64 PC | Windows 10/11 或 Linux | 联调与现场操作台，性能充足 |
| 可选 | ARM64 单板机 | 树莓派 4B/5（ARM Linux） | 便携地面站，需串口扩展与 5V 供电 |

> 说明：树莓派在整体架构中**已是机载端**（运行 `airship_link` 下传数据）。将其再作为地面站使用时，需额外承担打包 ARM 目标；如无便携硬需求，**PC 即可覆盖全部联调场景**。

### 1.2 硬件 / 系统要求
- **最低**：1 核 1 GB 内存、1024×600 分辨率
- **推荐**：2 核以上、2 GB+ 内存、1920×1080
- **显示**：Qt Widgets 自绘，无需 GPU，Intel/核显即可
- **串口**：至少一个 USB 转串口（数传）；Linux 下需对应驱动

### 1.3 串口权限（Linux 关键）
地面站需打开 `/dev/ttyUSB0` 等数传串口，普通用户默认无权限：

```bash
# 将当前用户加入 dialout 组（或 uucp），重新登录生效
sudo usermod -aG dialout $USER

# 查看数传设备是否被识别
ls -l /dev/ttyUSB* 2>/dev/null || echo "无串口设备"
```

Windows 下安装对应 USB 转串口驱动后，在「设备管理器→端口(COM 和 LPT)」确认 COM 号即可。

## 2. 打包工具（决策 #35）

> Qt 6 自带 `windeployqt`（Windows）与 `linuxdeployqt`（Linux，社区版，需配合 appimage 环境）。
> 打包目标 = 可执行文件 + 所需 Qt 运行库 + 平台插件，使目标机**无需安装开发环境**即可运行。

### 2.1 前置：生成 Release 构建

```bash
# 在工程根目录，新建发布构建目录
cmake -S . -B build-release -DCMAKE_BUILD_TYPE=Release
cmake --build build-release -j$(nproc)
```

产物：`build-release/lingyun_ground_station`（Windows 下为 `.exe`）。

### 2.2 Windows 打包（windeployqt）

```bat
:: 在开发者命令提示符（已配置 Qt 环境）下执行
set QT_BIN=C:\Qt\6.10.1\mingw_64\bin
set OUT=dist\lingyun-gcs

mkdir %OUT%
copy build-release\Release\lingyun_ground_station.exe %OUT%\

:: 自动拷贝 Qt 运行库 / 平台插件 / 编译器运行库
%QT_BIN%\windeployqt --release %OUT%\lingyun_ground_station.exe

:: 可选：压缩为单文件/安装包
%QT_BIN%\..\..\Tools\QtInstallerFramework\bin\archivegen lingyun-gcs.zip %OUT%
```

> 说明：工程依赖 `Qt6::PrintSupport`（报告导出）与 `Qt6::SerialPort`，`windeployqt` 会一并收集。

### 2.3 Linux 打包（linuxdeployqt / linuxdeploy）

推荐使用 `linuxdeploy` + `linuxdeploy-plugin-qt`（更通用、支持 AppImage）：

```bash
# 1) 准备工具（任选）：linuxdeploy + linuxdeploy-plugin-qt
# https://github.com/linuxdeploy/linuxdeploy

export QT_SELECT=qt6
export OUTPUT=dist/lingyun-gcs.AppImage

APP_DIR=dist/lingyun-gcs.AppDir
mkdir -p $APP_DIR/usr/bin
cp build-release/lingyun_ground_station $APP_DIR/usr/bin/

linuxdeploy --appdir $APP_DIR \
    -e build-release/lingyun_ground_station \
    -d packaging/lingyun-gcs.desktop \
    -i packaging/icon.png \
    --plugin qt --output appimage
```

> `linuxdeploy-plugin-qt` 会自动收集 Qt 插件与库，生成可双击运行的 AppImage。

### 2.4 免打包（开发/自用场景）
目标机已装 Qt6 时，可直接分发可执行文件：

```bash
# 仅拷贝可执行文件，运行时依赖系统已装的 Qt6 库
cp build-release/lingyun_ground_station /opt/lingyun-gcs/
```

## 3. Linux 桌面集成（可选）

创建 `packaging/lingyun-gcs.desktop`：

```ini
[Desktop Entry]
Type=Application
Name=灵云01 地面站
Comment=灵云01号 飞艇地面站
Exec=lingyun_ground_station
Icon=lingyun-gcs
Terminal=false
Categories=Utility;Science;
```

安装到系统菜单：

```bash
cp packaging/lingyun-gcs.desktop ~/.local/share/applications/
```

## 4. 部署验证清单

| 项 | 检查内容 |
|----|----------|
| 可执行 | 目标机双击/命令行可启动，无缺库报错 |
| 串口 | 能枚举并打开数传串口；Linux 已加入 `dialout` 组 |
| 配置 | 首次启动生成 `ground_station.json`（含 BOM）；导出快照/报告正常 |
| 异常 | 插入/拔除数传电台，链路状态与离线告警正确 |
| 数据 | 用 `tools/serial_simulator.py` 造数验证解析与显示 |
