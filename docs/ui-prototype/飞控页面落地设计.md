# 灵云01 地面站 · 飞控页面落地设计（对齐 UI 原型）

> 用途：将 `airship-gcs-prototype.html` 的**飞控页** 1:1 落地为 Qt 软件的设计依据。
> 硬性要求：Qt 落地后的飞控页与 UI 原型 HTML **视觉与交互完全一致**（同布局、同尺寸、同颜色、同动画、同操作逻辑）。
> 源码参考：`airship-gcs-prototype.html` 飞控模块（CSS ≈ L399-504，HTML ≈ L1062-1148，JS ≈ L3247-3364）。
> 数据依据：`docs/机载计算机对接文档/地面站对接协议.md` 第 5.5 节 `fc` 字段（仅 4G 链路打包）。

---

## 一、页面整体结构

飞控页为单页面 `#view-flight`，内部一个 `.fc-panel`（垂直 flex，gap 12px，占满视口）。**左右分栏**：左栏固定宽度显示飞艇信息，右栏地图自适应窗口。

```
fc-panel（flex column，flex:1，min-height:0，gap:12px）
├── fc-bar  顶栏横幅（横排徽章：标题 / 在线 / 已解锁 / 电池 / GPS / 告警 / 飞行模式）
├── fc-split 分栏主体（flex row，flex:1，min-height:0，gap:12px）
│   ├── fc-info  左栏（width:280px 固定，窄屏 240px，内容多时内部滚动）
│   │   ├── 姿态仪表卡（人工地平仪 168px + 数字标签，只读）
│   │   └── 电机状态卡（默认展开，flex:1 占满左栏剩余空间，3 组 10 台）
│   └── fc-map   右栏（flex:1，随窗口实时调整）
│       ├── 地图画布：网格背景 + 航迹线 + 起点 + 飞行器标记(带航向)
│       ├── 比例尺 fc-scale（左下角，100m）
│       └── 飞艇遥测悬浮窗 fc-ovl（右上角，8 项导航数据）
└── 全局底部状态栏 footer.statusbar（与所有页面统一显示，飞控页不隐藏）
```

---

## 二、顶栏横幅 `fc-bar`（视觉规范）

| 元素 | 样式 |
|---|---|
| 容器 | flex 横排，gap 12px，padding 10px 16px，1px 线框，圆角 12px，卡片底色 + 阴影，允许换行 |
| 标题「飞控」 | 飞艇图标 SVG（18×18，描边 primary，stroke-width 1.8）+ 文字 15px/700 |
| 在线徽章 `.fc-pill.ok` | 圆角胶囊，7px 绿点 + 「在线」；离线时 `.fc-pill`（无 ok）灰字灰点 |
| 飞行模式 `.fc-mode`（最右） | 主题色胶囊（primary 边框 + primary-soft 底 + primary 字），显示当前模式（如「定高」） |
| 已解锁 `.fc-pill.arm` | 锁图标 + 「已解锁」（绿）；未解锁 `.fc-pill.arm.off` 灰态 + 「已锁定」 |
| 电池 `.fc-batt` | 电池图标 + 电量百分比 + 电压（等宽字体，如 `85%` `367.2 V`） |
| GPS `.fc-pill` | 卫星图标 + `GPS 15 颗`（等宽数字） |
| 告警 `.fc-pill.ok/.warn` | 警示三角图标 + 数字；0 绿色(ok)，>0 黄色(warn)；**可点击弹出告警明细**（见第六节） |

**徽章顺序（从左到右）**：标题 → 在线 → 已解锁 → 电池 → GPS → 告警 → 飞行模式。

### 2.1 徽章通用样式
- `.fc-pill`：内联胶囊，圆角 999px，padding 3px 12px，12px/700，图标 13px（stroke:currentColor）。
- 状态色：绿 `--ok` / 黄 `--warn` / 灰 `--text-2`；底色用 `--ok-soft` / `--warn-soft` 半透明系。

## 三、左栏 `fc-info`（固定宽度）

- `.fc-info`：width 280px（`@media(max-width:1000px)` 时 240px），flex column，gap 10px，`overflow-y:auto` 内部滚动。
- 卡片 `.fc-float`：1px 线框，圆角 12px，卡片底色 + 阴影，`flex-shrink:0`。

### 3.1 姿态仪表卡
- 圆形人工地平仪（SVG，viewBox 210×210，渲染 168px）：天空/地面双色球面 + 俯仰格线 + 横滚指针 + 航向刻度（360/270/090）。
- 动态：横滚旋转（`#fcAiBall` transform rotate）、俯仰平移（`#fcAiPitch` translate）。
- 仪表下方数字：`俯仰 +3.2° · 横滚 -1.4° · 航向 127.5°`（等宽字体 12px/600）。
- 状态角标：正常（绿 `.tag.g`） / 数据丢失（灰）。

### 3.2 电机状态卡（默认展开，占满底部）
- **默认展开**（HTML 初始带 `open` class），展开后 `.fc-mfold.open{flex:1}` 占满左栏剩余空间，底部贴齐；窗口高度变化时随动伸缩。
- 点击折叠头收起（只剩头部），再点展开恢复占满；箭头朝上 ▴ 表示展开。
- 分组（共 10 台，标题「10 台 · 只读」）：
  - **推进电机**（4 台，进度条 primary 色）：推进·左前 / 左后 / 右后 / 右前
  - **上升电机**（4 台，进度条 ok 色）：上升·左前 / 左后 / 右后 / 右前
  - **下降电机**（2 台，进度条 ok 色）：前下降 / 后下降
- 每台行：名称（88px）+ 转速进度条（归一化到上限）+ 转速值（rpm）+ 温度值（°C）。
- 温度 > 阈值（65°C）时温度数字变黄（`.t.w`），并触发横幅告警计数。

---

## 四、右栏地图 `fc-map`（自适应）

- `.fc-map`：flex:1，min-width:0，相对定位，圆角 12px，网格背景（`linear-gradient` 56px 网格，深浅色模式各一套）。
- SVG 画布：`viewBox="0 0 100 100" preserveAspectRatio="none"`，随窗口等比拉伸：
  - 航迹线 `#fcTrack`：虚线（primary，stroke 1.5，opacity .5），最多 180 点。
  - 起点 `#fcStart`：灰色小圆。
  - 飞行器 `#fcShip`：三角箭头，`translate(x,y) rotate(航向)` 动态更新。
- 比例尺 `.fc-scale`：左下角，4px 高 90px 宽，标注「100 m」。
- 飞行器移动：沿 `yaw` 方向，速度取地速（归一化 0.15~0.8），触边反弹（保持航向连续性）。

### 4.1 飞艇遥测悬浮窗 `fc-ovl`（右上角）
- 深色半透明底（rgba 白 0.9 / 深色模式 rgba 22,33,58 .92）+ backdrop blur，圆角 12px，`pointer-events:none`。
- 标题「飞艇遥测」+ 绿点；共 **8 项**（等宽字体，label 左 / 值右）：

| 项 | 数据源 |
|---|---|
| 高度 | `fc.alt` (m) |
| 地速 | `√(fc.vx² + fc.vy²)` (m/s) |
| 东向速度 | `fc.vx`（带 +/− 符号） |
| 北向速度 | `fc.vy`（带 +/− 符号） |
| 升降率 | `fc.vz`（带 +/− 符号） |
| 航向 | `fc.yaw` (°) |
| 经度 | `fc.lon`（6 位小数） |
| 纬度 | `fc.lat`（6 位小数） |

## 五、数据模型（对接协议 `fc` 字段映射）

| `fc` 字段 | 类型/单位 | UI 位置 | 派生说明 |
|---|---|---|---|
| `online` | bool | 顶栏「在线」徽章 | - |
| `armed` | bool | 顶栏「已解锁」徽章 | - |
| `mode` | string | 顶栏飞行模式徽章 | - |
| `batt_v` | V | 顶栏电池电压 | - |
| `batt_pct` | 0~1 | 顶栏电池百分比（×100%） | - |
| `roll` / `pitch` | deg | 姿态仪表 | - |
| `yaw` | deg | 姿态仪表航向 + 悬浮窗航向 + 地图飞行器朝向 | - |
| `alt` | m | 悬浮窗高度 | 相对起飞点高度 `alt_rel` |
| `vx` | m/s | 悬浮窗东向速度 | ENU 东向 |
| `vy` | m/s | 悬浮窗北向速度 | ENU 北向 |
| `vz` | m/s | 悬浮窗升降率 | ENU 天向 |
| `lat` / `lon` | deg | 悬浮窗经纬度 + 地图飞行器定位 | 6 位小数 |

> **说明**：对接文档 `fc` 的 14 个字段已全部集成。`groundspeed` / `climb_rate` 未打包（见协议 5.7 节），地速与升降率由 `vx/vy/vz` 派生，符合协议现状。`fc` 仅由 4G 链路打包，若本地数传需要显示飞控数据，需机载 `link_node` 扩展订阅（协议第 11 节）。

## 六、告警明细弹窗（只读）

- **触发**：点击顶栏「告警」徽章 → 复用全局 `openModal` 打开「飞控告警明细」弹窗。
- **内容**：最近告警列表（最多 8 条），每条：级别角标（WARN 黄）+ 消息（如「上升·右前 温度 65°C 超限」）+ 时间（HH:MM:SS）。
- **记录规则**：电机温度超 65°C 阈值时**边沿触发**记一条；无历史告警时显示「当前无告警」。
- 徽章数字表示**当前瞬时告警数**（0 绿 / >0 黄），弹窗显示**最近历史**，二者语义互补。
- 弹窗右上 × 关闭；整窗只读，无任何控制元素。

---

## 七、动态行为（模拟数据）

- 定时（1s）`setInterval(tick,1000)` 刷新：
  - 姿态：`roll`/`pitch`/`yaw` 小幅波动（yaw 0-360 归一化）。
  - 导航：`alt` 漂移、`vx/vy/vz` 漂移、`lat/lon` 微动（±1e-6）。
  - 电池：`batt_v` ±0.3V、`batt_pct` ±0.4% 微动。
  - 电机：转速抖动（±20rpm 扰动）+ 温度缓变（1 台周期抬升演示告警）。
  - 链路：GPS 颗数 15~16 随机。
- 地图飞行器：沿 `yaw` 方向移动并追加航迹点（超 180 点丢旧）。

---

## 八、与全局布局的关系

- **底部状态栏**：飞控页与监控/摄像头/图示/设置等页面**统一显示**全局 `footer.statusbar`（链路/GPS/数据率/链路质量/告警/运行时长/最新告警/本地时间），不做隐藏。
- **导航**：左侧导航保留「飞控」入口；「地图」独立入口已删除（并入飞控页）。
- **快捷键**：数字键 `3` = 飞控页（`switchView` 统一切换，所有页面显示状态栏）。

## 九、Qt 落地注意

1. **纯展示、不控制**：页面无任何指令按钮/模式切换/参数编辑；Qt 落地时数据走 `bridge` 的 `fc` 字段（online/armed/mode/batt_v/batt_pct/roll/pitch/yaw/alt/vx/vy/vz/lat/lon），无需回传控制指令。
2. **姿态仪表**：建议 Qt 用 Canvas 绘制（人工地平仪 = 横滚旋转 + 俯仰平移 + 航向刻度），与电源链路/图示同路线。
3. **地图**：原型为抽象网格 + 比例尺。Qt 落地可复用现有地图模块（`MapView.qml`，天地图/OSM 瓦片 + 缓存），将飞行器/航迹落到真实地图坐标（lat/lon + yaw 朝向），替换抽象网格。
4. **电机状态**：当前 10 台（推进 4 + 上升 4 + 下降 2）为模拟数据；对接协议 `fc` 仅含 `motor_outputs[8]` 且未打包，真实电机转速/温度需机载扩展打包（或由其他链路提供）后才能替换模拟值。
5. **告警明细**：弹窗历史记录为本地模拟；真实接入后建议由地面站对 `alarm/fault/online` 字段做本地阈值与状态跳变判断（协议第 9 节），或扩展机载打包告警事件流。
6. **数据新鲜度**：`online` 已用于在线/离线徽章；实机接入后可补充「最后更新时间」角标（与监控页数据新鲜度机制一致）。
