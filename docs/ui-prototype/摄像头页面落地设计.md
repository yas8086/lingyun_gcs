# 灵云01 地面站 · 摄像头页面落地设计（对齐 UI 原型）

> 用途：将 `airship-gcs-prototype.html` 的**摄像头监控页** 1:1 落地为 Qt 软件的设计依据。
> 硬性要求：Qt 落地后的监控页面与 UI 原型 HTML 的摄像头页面**视觉与交互完全一致**（同布局、同尺寸、同颜色、同动画、同操作逻辑）。
> 源码参考：`airship-gcs-prototype.html` 摄像头模块（CSS ≈ L423-513，HTML ≈ L982-1016，JS ≈ L2342-2640）。

---

## 一、页面整体结构

摄像头页为单页面 `view-camera`，内部一个 `.cam-panel`（垂直 flex，gap 12px，占满视口）：

```
cam-panel（flex column，flex:1，min-height:0，gap:12px）
├── cam-head        头部卡片（标题 / 网口状态 / 链路 meta / 拉流设置按钮）
├── cam-tabs        相机 tab 栏（每个相机一个按钮，横向可滚动）
├── cam-stage       视频舞台（居中容器）
│   └── cam-grid    CSS Grid 网格（布局档位决定行列，含 cam-view 画面格）
└── cam-bar         底部控制条（截图/录像/OSD/比例/重连/说明/布局切换）
```

## 三、相机 tab 栏 `cam-tabs`

- 每个相机一个 `.cam-tab` 按钮，JS 按 `camCfg` 动态生成，**数量不固定**。
- tab 内容：状态点（6px 圆点）+ 相机名称。
- 状态点颜色：**启用=绿(--ok)，停用=灰(--off)**。
- 选中态（active）：**蓝色底(--primary) + 白字**；未选中：白底灰字；hover：primary 描边 + 文字变色。
- 尺寸：圆角 8px，padding 5px 12px，12px/600，gap 6px；按钮间距 6px。
- 容器：`flex-wrap:nowrap` + `overflow-x:auto`（相机多时横向滚动，不换行）。
- **交互语义（关键）**：tab 是**多选开关**，选中高亮的 tab 即当前显示的画面集合（见第五节）。

## 四、视频舞台与画面格

### 4.1 舞台 `cam-stage`
- 弹性占满剩余高度（flex:1，min-height:0），flex 居中容器，overflow hidden。
- padding 8px，浅灰底(--card-2)，1px 线框，圆角 12px。
- 内部 `cam-grid` 的**整体宽高由 JS 按「画面比例」计算**（见 4.4），grid 内部单元格均分。

### 4.2 网格 `cam-grid`（按布局档位）
- `display:grid; gap:10px; flex:0 0 auto`。
- 档位→行列：单路 1×1；双路 2 列 1 行；四路 2×2；全部=`ceil(sqrt(选中数))` 列、行自动补足。
- 窄屏断点（<900px）：强制 1 列流式（`grid-template-columns:1fr!important`）。

### 4.3 画面格 `cam-view`（每个相机一个）
| 元素 | 说明 |
|---|---|
| 容器 | 黑底，圆角 12px，1px 线框 + 阴影；**选中**（active）= primary 描边 + 2px ring 光圈 |
| 画面占位 `cam-frame` | 深蓝径向渐变（`#26334d→#0d1524→#060a12`）+ 白色摄像头描边图标（120px，opacity .12）+ 居中文字：启用时「`{名称} · 画面占位` / 接入网口视频流后实时显示」，停用时「`{名称} · 未启用` / 等待拉流设置」（12px，#7d8ca6） |
| 标签 `cam-tag`（左上角） | 黑 45% 透明底 + 模糊，白字 11px/700，「`{名称} · LIVE/OFFLINE`」；状态点呼吸动画（绿=正常脉冲 / 红=离线脉冲，1.6s） |
| OSD `cam-osd`（右下角） | 黑 40% 透明底 + 模糊，等宽字体 10.5px，#cfe0ff；三行：①时间 ②LAT/LON ③ALT/SPD/HDG；**仅启用相机显示**；可整体开/关（.hidden） |
| 悬浮控制 `cam-ov`（右上角） | hover 才显示（opacity 0→1，150ms）：放大 ⛶ + 截图 📷，各 26px 圆形黑底白字按钮，hover 变 primary 底 |

### 4.4 画面比例切换（底部按钮）
- 循环档位：**16:9 → 4:3 → 1:1 → 填充**。
- 计算：取舞台可用尺寸（扣除 16px padding），按比例计算网格宽高并**居中**；「填充」= 100%×100%。
- 视图隐藏（切换到其他页面）时不计算，切回摄像头页时重算；窗口 resize 时重算。

### 4.5 云台控制浮动盘（PTZ）
- **判定**：只有「云台相机」才显示控制盘。条件 = 焦点格 && 已选中 && 已启用 && `ptz=true`（四条件同时满足）。
- **云台相机如何确定**：拉流设置里给每个相机勾选「云台控制」开关（CamConfig.`ptz` 字段，持久化）。默认吊舱相机带云台（gimbal），前视/后视/地面默认不带，可自行勾改。
- **形态**：悬浮在焦点画面格**左下角**，半透明深色底（rgba(8,14,26,.74)）+ 背景模糊，圆角 10px，与 cam-tag/cam-osd 视觉统一。
- **内容**：头部「云台 · {相机名}」+ 折叠按钮；主体 3×3 方向键（8 向 + 中心红色停止）+ 右侧竖排变倍 ＋/－。按钮 28×28px，hover 变主题色底。
- **交互**：方向/变倍按下即发送指令（按住 260ms 间隔连续），松开停止；折叠后仅剩头部标题。
- **焦点切换**：点 tab 或点画面格即把该路设为焦点（`focusIdx`），控制盘跟随移动；焦点格有白色加粗描边（区别于普通选中的主题色描边）。
- **视觉层级**：z-index 4，位于 cam-ov（3）之上、画面内容之下。

## 五、布局档位与 tab 多选交互（核心逻辑）

**状态**：`selected` = 当前选中的相机索引集合；`layMode` = 布局档位。

### 5.1 布局档位按钮（`.cam-lay`，右侧）
- 四个按钮：**单路（1 点）｜双路（2 点横排）｜四路（2×2 田字点阵）｜全（文字「全」）**。
- 26×26px，圆角 6px，点 5px；选中 = primary 底白字。
- 档位→**上限**：单路 1 / 双路 2 / 四路 4 / 全 = 相机总数（无上限）。

### 5.2 tab 点击（多选 toggle）
- 点已选中的 tab → **取消**（画面消失）。
- 点未选中的 tab → **选中**（画面出现）；若已满上限，**自动顶掉最早选中的**那个（FIFO），保持数量不变。
- 全部取消 → 画面区显示占位「未选择相机，请点击上方 tab 选择」（虚线框提示）。

### 5.3 切换布局档位时的默认处理
- 切到**全**：**强制全选所有相机**（含之后新增的相机，再点一次「全」即恢复全选）。
- 切到**单路/双路/四路**：
  1. 裁剪：选中数超过新上限时，移除超出的（**保留最早选中的**）。
  2. 补足：不足上限时，按相机顺序从 0 开始补齐未选中的，直到满上限。
- 布局档位持久化到 localStorage（`gcs_cam_lay`），刷新后保留。

### 5.4 网格排布随选中数自适应
- 非「全」档位：固定形状（1 格 / 2 列 1 行 / 2×2）。
- 「全」档位：按**当前选中数量**自动均分（选中 4 个→2×2，5 个→3 列，6 个→3×2），取消几个就少几个格，始终铺满不空位。

## 七、相机拉流设置弹窗

> 主弹窗「相机拉流设置 · RTSP」；删除/清空类危险操作走**第二层叠加确认框**（z-index 更高、遮罩更深，不替换主弹窗）。弹窗 `max-height:92vh`，内容超高时**弹窗内部滚动**（标题固定，滚动条在内容区）。

### 7.1 结构
1. **相机列表**：每行 = 状态点 + 相机名称 + **「云台」标签**（仅云台相机，绿色描边小标签）+ 掩码地址（`rtsp://user:*****@ip:port/path`，未配置显示「未配置地址」）+ 状态（已启用/已停用/未配置）+ **✕ 删除按钮**。无相机时显示「尚未配置相机，点击下方添加相机新建」。
2. **编辑表单**（切换「编辑相机」下拉即切换当前编辑对象）：
   - 相机名称（可编辑）
   - RTSP 完整地址（**粘贴后自动解析**填充分项；手动改分项反向同步地址）
   - 启用该相机（checkbox）
   - **云台控制（checkbox）**：勾选 = 该相机为云台相机（PTZ），画面格才显示云台控制盘；默认吊舱勾选
   - IP 地址 / 端口（可空默认 554）/ RTSP 路径（可空）/ 用户名（可空）/ 密码（可空）
   - 码流（主码流/子码流）+ 传输（TCP/UDP）+ 帧率（15/20/25/30）三连下拉
3. **底部操作**：「＋ 添加相机」（绿描边）｜「清空当前相机」（红描边）｜「保存设置」（蓝渐变底）。

### 7.2 行为
- **添加相机**：自动命名「新相机 N」（N=当前数量+1），默认停用、地址为空，编号 `id=cam_新序号`（不复用，稳定）。
- **保存设置**：写回配置 → 持久化 → 刷新摄像头页（tab 状态点、meta）→ 关闭弹窗 + toast「拉流设置已保存」。
- **清空当前相机**：叠加确认框，明确目标相机名 + 「清空后该相机将停用，地址参数为空，此操作不可撤销」；确认后**保留 id/名称**，仅清空地址参数与停用。
- **删除相机**：叠加确认框「确定要删除 {名称} 吗…不可撤销」；确认后整行移除（含配置），删除当前编辑项自动切到相邻项，摄像头页 tab/网格同步更新。
- 确认框操作：取消 = 仅关确认框、保留主弹窗；Esc 可关闭两层弹窗。

### 7.3 RTSP 地址解析规则
`rtsp://[user[:pass]@]ip[:port][/path]` —— 用户名/密码/端口/路径均可省略；端口缺省 554，路径缺省 `/`。

## 八、数据模型（C++ 对应结构）

```cpp
// 每路相机配置，JSON 持久化，主键 id 稳定（增删/编辑均以 id 定位，不依赖数组下标）
struct CamConfig {
    QString id;        // "cam_0" 主键，删除后不复用
    QString name;      // 可编辑名称，默认 前视/后视/吊舱/地面、新相机N
    bool    enable;    // 是否启用（决定 LIVE/OFFLINE、是否显示 OSD、占位文案）
    bool    ptz;       // 是否为云台相机（决定画面格是否显示云台控制盘）；默认吊舱=true、其余=false
    QString ip;        // 空=未配置地址
    int     port;      // 默认 554
    QString path;      // RTSP 路径，可空
    QString user;      // 可空
    QString pass;      // 可空
    QString stream;    // "主码流"/"子码流"
    QString transport; // "TCP"/"UDP"
    int     fps;       // 15/20/25/30，默认 25
};
// 持久化：JSON 数组，localStorage key `gcs_cam_cfg`；布局档位 key `gcs_cam_lay`
```

**迁移兼容**：旧数据（无 id/name/ptz 字段）加载时按索引自动补默认名 + 生成 id + 补齐云台标记（按索引对应默认，吊舱=true），再回写；不校验长度，数量以实际存储为准。

## 九、Qt 落地映射建议

| 原型 | Qt 建议 |
|---|---|
| cam-head 头部 | QWidget 内 QHBoxLayout + QLabel/QPushButton，主题色经 QSS/调色板 |
| cam-tabs 动态 tab | 横向 FlowLayout 或 QScrollArea+QHBoxLayout 动态 addWidget；或用 QML Repeater |
| cam-stage/cam-grid | QGridLayout 动态 addWidget；或 QML Grid 动态 columns |
| cam-view 画面格 | 自定义 `CameraWidget`（QFrame 黑底 + QLabel 占位 + 右上/左上/右下覆盖层），视频流阶段接入 QtMultimedia/QtAV/vlc-qt 播放 RTSP |
| 占位渐变 | QSS 不支持渐变模拟 → QPainter 自绘或使用 QML ShaderEffect/Canvas 还原径向渐变 |
| OSD/标签覆盖 | 画面格上叠加多个 QLabel（绝对定位），OSD 可整体显隐 |
| 状态点呼吸动画 | QVariantAnimation/QTimer + 调整 shadow 色；QML 用 SequentialAnimation |
| 拉流设置弹窗 | QDialog；确认框用第二层 QDialog（或 Dialog 模态叠加），注意 z 序 |
| 增删/配置 | 配置读写复用 `config_manager` JSON 风格，信号槽通知摄像头页刷新 |
| tab 多选状态 | `QSet<int> selected` + 布局档位枚举；信号 `selectionChanged` / `layoutChanged` |
| 比例自适应 | resizeEvent 中重算网格宽高（对应原型 fitCam） |
| 云台控制盘 | 自定义 `PtzPanel`（QML Item / QWidget 自绘：3×3 方向键 + 变倍），信号 `ptzMove(camId, dir)` / `ptzStop(camId)` / `ptzZoom(camId, delta)`；长按连续用 QTimer |
| 云台焦点 | 独立 `focusCamId`（点击画面格/tab 更新），渲染条件 `focus && selected && enable && ptz` |
| 方向图标 | 原型用 Unicode 箭头（◤▲◥◀●▶◣▼◢），Qt 建议换 SVG 图标保证跨平台字体一致 |

### 关键状态/边界
- 相机可删到 0：列表空提示 + 网格空；仍可添加。
- 选中可全空：画面区占位提示。
- 相机多时 tab 横向滚动；窄屏网格单列。
- 布局档位与选中集跨会话持久化。
