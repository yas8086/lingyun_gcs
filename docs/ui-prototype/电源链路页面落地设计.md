# 灵云01 地面站 · 电源链路页面落地设计（对齐 UI 原型）

> 用途：将 `airship-gcs-prototype.html` 的**电源链路拓扑页**（图示 → 电源链路）落地为 Qt 软件的设计依据。
> 硬性要求：Qt 落地后的电源链路页与 UI 原型 HTML **视觉与交互完全一致**（同布局、同两域分区、同节点/连线、同颜色、同流动动画、同缩放逻辑）。
> 源码参考：`airship-gcs-prototype.html` 电源链路模块（CSS ≈ L562-614，HTML SVG ≈ L1083-1270，JS `updateTopo` ≈ L1835-1974，缩放重排 ≈ L2972-3100）。
> Qt 现状：`src/qml/views/TopoView.qml` 已有**旧版**电源链路（`powerPanel` 组件 + `topoCanvas` Canvas 绘制，横排 5 节点 + 单母线，L500-654）。本文档为将其升级到原型最新布局的落地依据。

---

## 一、页面整体结构

电源链路是「图示」页默认面板（`treeNode===0`，复用现有 `powerPanel` 装载机制），结构如下：

```
powerPanel（Item，占满右侧大卡，margins 12）
├── 图例区      Row：在线(绿点) / 告警(黄点) / 离线(灰点)   ← 现有 L538-551 保留
└── topoCanvas  Canvas（占满剩余，绘制两域 + 母线 + 节点 + 连线）
```

> 技术路线沿用现有 **Canvas 2D 绘制**（与 `topoCanvas` 一致），不引入 SVG/SceneGraph 节点，保证与现有温度热力图、曲线等并行渲染平滑；缩放由 Canvas 按控件尺寸**动态计算坐标**实现（对应原型 `relayoutTopo`）。

---

## 二、两域布局规范（核心）

原型 SVG viewBox `0 0 1200 820`，Qt 中以 Canvas 逻辑坐标复刻；Canvas 尺寸变化时按 `scaleX/scaleY` 各轴独立缩放（见第六节）。

### 2.1 灰框分区
| 区域 | 逻辑坐标（y） | 高度 | 占比 |
|---|---|---|---|
| 高压直流域 | y=10 ~ 408 | 398 | 50% |
| 48V 弱电域 | y=413 ~ 810 | 397 | 50% |

- 两域上下**五五分**；灰框四边距白色容器 **10px** 一致。
- 灰框样式：卡片浅灰底（`colCard2`）+ 1px 线框（`colLine`）+ 虚线（dash `6 5`），左上角标题「高压直流域」「48V 弱电域」（13px/700，`colText2`）。

### 2.2 中轴对称
所有排节点关于**中轴线 x=600** 左右对称（成对节点中心关于 600 对称），排内间距等宽。

| 部分 | 样式 |

| 副值 | 12px 等宽 `colText2`，居中 |

**状态色**（三态）：
| 状态 | 表现 |
|---|---|
| 正常 | 默认 |
| 告警（warn） | 卡描边变**黄色** `colWarn`（内容不变） |
| 离线（off） | 卡描边/图标/文字变**灰** `colOff`，底 `colBg2`，透明度 .6 |

### 5.2 连线（对齐原型 `.topo-link`）
| 部分 | 样式 |
|---|---|
| 线体 | 主色 2.5px 圆头虚线（dash `8 6`） |
| 流动动画 | `lineDashOffset` 由 Timer 每 50ms 递增 0.7（周期 14），实现虚线向 MPPT/负载方向流动 |
| 箭头 | 线端小三角（约 6×6），指向电流方向（光伏→MPPT、母线→电机、DCDC→母线） |

| 双向线（lb1/lb2） | 双箭头 + 充电=`colOk` 绿 / 放电=`colErr` 红，流动反向 |
| 离线 | 线/标注变灰 `colOff` 且**停止流动动画** |

## 六、动态行为

### 6.1 数据刷新
- 复用 `themeRoot.dataTick` 节拍触发 `topoCanvas.requestPaint()`（现有 `Connections` 机制保留）。
- 数据源（`bridge.value(device,key)` / `bridge.online(device)`，现有 tPv/tCi/tOut… 函数可扩展）：
  | 设备 | 字段 | 用途 |
  |---|---|---|
  | mppt | pv_p / pv_v / charge_i | 主囊功率/电压、MPPT1 充电电流 |
  | mppt2（新增） | pv_p / charge_i | 副囊功率、MPPT2 充电电流 |
  | bms | soc / pack_v / pack_i | 102S SOC/总压/总电流 |
  | dcdc | out_p / out_v / temp | DCDC 输出功率/电压/温度、母线2 负载 |
  | backup（新增，可模拟） | soc / v | 12S 备用锂电 |
  | 电机（可模拟） | rpm | 推进/上升/下降电机转速 |

### 6.2 母线负载标注
- 母线1：`第一级母线 · {总压}V · 负载 {推进电机总功率+DCDC输入}W`
- 母线2：`第二级母线 · 48V · 负载 {DCDC 输出功率}W`

### 6.3 告警状态（黄边框）
| 节点 | 条件 |
|---|---|
| DCDC | 温度 > 43℃ |
| 102S | SOC < 20% |
| MPPT 1/2 | 转换效率 < 90% |
| 推进电机 | 转速 > 520 rpm |
| 上升电机 | 转速 > 2200 rpm |
| 下降电机 | 转速 > 1500 rpm |

### 6.4 离线联动置灰
| 离线设备 | 置灰范围 |
|---|---|
| DCDC | DCDC / 12S / 6 小电机 / 载荷 节点 + l4/l5/lb2/l6a-f/l7 连线 |
| BMS | 102S 节点 + lb1 连线 |
| MPPT | MPPT1/2 节点 + l1a/l1b/l2a/l2b 连线 |

### 6.5 节点悬停详情
- HoverHandler 捕获节点卡悬停，显示浮动详情框（或复用现有 ToolTip）：标题 + 功率/电压/电流/转速/SOC/温度等实时参数。

### 6.6 窗口缩放（等比，各轴独立）
对应原型 `relayoutTopo`：Canvas 尺寸变化时计算
```
sx = (W-20)/1180      // 水平跟随宽度
sy = (H-25)/800       // 垂直跟随高度
mapX(bx) = 10 + (bx-10)*sx
mapY(by) = by<=408 ? 10 + (by-10)/398*hvH : (10+hvH+5) + (by-413)/397*wvH
hvH = round((H-25)/2)  // 五五分
```
- 卡片/节点用 `s = min(sx,sy)` 等比缩放（不变形），位置用 mapX/mapY（各轴独立）。
- 灰框铺满 Canvas、四边距 10px、五五分；箭头随 `s` 缩放（保持小巧）。
- 首次显示与 resize 时重算（复用 `onDataTickChanged` 之外的尺寸变化信号，如 `onWidthChanged/onHeightChanged`）。

## 七、Qt 落地映射表

| HTML 原型 | Qt 落地 |
|---|---|
| `.topo-canvas` 白色容器 | `topoCanvas` Canvas（占满 powerPanel） |
| `.topo-zone` 两个灰框 | Canvas 内两段圆角矩形 + 标题文字 |
| `.topo-node` 节点卡 | Canvas 绘制矩形+图标+文字，或自定义 `PowerNode` 组件（QML Item） |
| `.topo-bus` 母线带 | Canvas 粗线（5px）+ joint 圆点 |
| `.topo-link` 连线 | Canvas 虚线 + `lineDashOffset` 流动 + 箭头三角 + 标注 |
| `.topo-link.bi` 双向线 | 双箭头 + 充电/放电着色 |
| `updateTopo` 数据刷新 | 现有 `tPv/tCi/tOut…` 扩展 + `onDataTickChanged` 重绘 |
| `relayoutTopo` 缩放 | Canvas 尺寸变化信号动态计算坐标 |
| 告警 `.warn` | Canvas 内按条件切换卡描边为 `colWarn` |
| 离线 `.off` | Canvas 内按 `bridge.online()` 置灰 + 停流动 |
| 悬停 title | HoverHandler + ToolTip / 自定义浮动框 |

> 建议：节点卡数量固定（本页 18 个），直接用 **Canvas 集中绘制**（与现有 topoCanvas 一致），避免 18 个 QML 组件带来的实例开销；如需悬停/点击，可在 Canvas 上方叠加透明 `MouseArea`/`HoverHandler` 命中检测（按节点矩形包围盒判断）。

## 八、与现有 TopoView 电源链路的差异（迁移点）

| 维度 | 现有 Qt（旧） | 原型（目标） |
|---|---|---|
| 布局 | 横排 5 节点、单母线 | **两域五五分 + 双母线 + 4 排 18 节点** |
| 分区 | 无灰框 | 高压直流域 / 48V 弱电域 |
| 光伏 | 单组 | 主囊 + 副囊分别接 MPPT1/MPPT2 |
| 电机 | 无 | 4 推进电机 + 6 小电机 + 载荷 |
| 电池 | BMS 单卡 | 102S（高压域）+ 12S（弱电域） |
| 母线 | 无标签 | 显示电压 + 负载功率 |
| 缩放 | 固定布局 | 各轴独立等比、灰框铺满五五分 |
| 告警/悬停 | 无 | 黄框告警 + 离线联动 + 悬停详情 |

迁移即重写 `powerPanel` 内 `topoCanvas` 的 `onPaint` 逻辑（保留流动 Timer、图例、`onDataTickChanged` 重绘等骨架）。

## 九、开发步骤与验收清单

1. 重写 `topoCanvas.onPaint`：绘制两域 → 母线 → 连线 → 节点，全部用原型坐标常量。
2. 数据绑定：扩展 `tPv/tCi/…` 为完整字段（主囊/副囊/102S/MPPT1-2/DCDC/12S/电机/载荷），离线判断 `off()` 覆盖 BMS/MPPT/DCDC。
3. 动态：母线负载标注、告警黄框、离线联动置灰、悬停详情。
4. 缩放：Canvas `onWidthChanged/onHeightChanged` 调用重排（各轴独立 + 五五分 + 铺满）。
5. 验收对照：
   - [ ] 两域五五分、四边距 10px、灰框铺满、中轴对称
   - [ ] 18 节点 + 双母线 + 全部连线与原型坐标一致
   - [ ] 虚线流动动画、箭头方向、功率/电流标注正确
   - [ ] 母线1→DCDC 跨域线不被推进电机遮挡
   - [ ] DCDC 离线 → 48V 段整体置灰停动画；BMS/MPPT 离线 → 对应段置灰
   - [ ] DCDC 温度 >43℃ 节点变黄框告警
   - [ ] 悬停节点显示实时参数详情
   - [ ] 窗口缩放时灰框铺满、内容等比、四边距一致
   - [ ] 实机运行无 QML 错误（沙箱内仅编译 + `timeout 8` 查加载日志，运行由真机验证）
