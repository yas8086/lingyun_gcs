## 十、QML 前端落地记录（2026-08-12）

> 按《2026-08-12-灵云地面站全面开发》计划，以 Qt Quick 方式复刻原型视觉，实行三层架构（C++ 后端 + QML 前端 + `TelemetryBridge` 桥接层），与既有 Qt Widgets 版并存。

| 模块 | QML 落地 | 桥接能力 |
|------|----------|----------|
| 监控页 | 飞艇横幅、设备卡（在线灯/状态）、响应式 Grid 3→2→1、QtCharts 实时曲线（滚动 120 点）、告警列表（确认）、底部状态栏 | `value/online/readinessState/ports/openSerial` |
| 告警（#20） | 告警列表 + 单行/全部确认 + 未确认计数 | `alarms/confirmAlarm/confirmAllAlarms/unconfirmedCount` |
| 温度（#26/#28） | `TempView`：LoRa 节点（温度/压力+告警）、统计、历史 CSV 导出 | `loraNodes/exportTempCsv`（历史环形 200） |
| 自检/就绪度（#11/#12） | `SelfCheckView`：11 项自检 + 就绪度聚合 | `readinessState` |
| 设置（#24/#29/#30） | `SettingsView`：串口/波特率、偏好（温度单位/告警声音/曲线窗口）、主题、模块可见性 | `configTempUnit/configAlarmSound/configChartWindow/configHiddenModules`（JSON 持久化） |
| 紧急操作（#21） | 动作选择 + 滑动确认弹窗，执行记录严重告警 | `addAlarm` |

**验收**：`cmake --build build` 全目标通过；`ctest` 6/6 全绿（含新增 `test_bridge_integration`）；`QT_QPA_PLATFORM=offscreen ./lingyun_gcs_qml` 启动无 TypeError；socat + serial_simulator 真实虚拟串口端到端数据流验证通过。

**遗留**：地图/飞控视图占位（#1/#2）；紧急操作与告警声音为演示/受控行为，硬件指令下沉至对接阶段。
