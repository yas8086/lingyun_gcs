# 灵云01 地面站 · 自检页面落地设计（对齐 UI 原型）

> 用途：将 `airship-gcs-prototype.html` 的**自检页** 1:1 落地为 Qt 软件的设计依据。
> 硬性要求：Qt 落地后的自检页与 UI 原型 HTML **视觉与交互完全一致**（同布局、同尺寸、同颜色、同动画、同操作逻辑）。
> 源码参考：`airship-gcs-prototype.html` 自检模块（CSS ≈ L264-290，HTML ≈ L1068-1079，JS ≈ L1793-1982；就绪度聚合 JS ≈ L1991-2006）。
> 功能状态：2026-08-27 全面测试通过（数据取值、三态渲染、参数编辑校验、持久化、就绪度联动、**自定义项动态增删**均验证无误）。

---

## 一、页面定位与功能概述

自检页是**起飞前检查工具**：按用户可编辑的阈值规则，对监控页实时数据做周期判定，输出逐项 通过/失败/停用 三态结果，并聚合为整机就绪度分级。

核心能力：

| 能力 | 说明 |
|---|---|
| 11 项预置自检 | BMS×5、MPPT×3、DCDC×3（详见第四节定义表） |
| **参数可编辑** | 每项独立弹窗编辑：启用开关、检查方式、比较符、阈值 |
| **动态增删自定义项** | 「＋ 新增自检项」按钮创建自定义检查项（元信息+判定参数一体配置），仅自定义项可删除（垃圾桶）；内置 11 项不可删 |
| 三态判定 | ✓ 通过 / ✗ 失败(阻塞起飞) / – 已停用(跳过) |
| 参数持久化 | localStorage `gcs_checkcfg`，按 id 合并默认值，自定义项全字段存储 |
| 就绪度聚合 | 0 项失败=就绪可飞 / 1 项=起飞受限 / ≥2 项=不可起飞 |
| 周期自动刷新 | 每 10 秒重跑全部检查项 |

**只读原则**：本页只读监控数据并判定，不含任何设备控制指令。

## 四、自检项数据模型

### 4.1 预置定义 `CHECK_DEFS`（JS ≈ L1836）

| id | dev | name | 取值字段 fid | 单位 | 默认模式 | 默认阈值 |
|---|---|---|---|---|---|---|
| bms_online | BMS | 链路在线 | — | — | none | 仅在线 |
| bms_packv | BMS | 总压正常 | pack_v | V | range | 360 ~ 380 V |
| bms_soc | BMS | SOC 充足 | soc | % | single/gt | > 30% |
| bms_maxt | BMS | 最高温度 | max_t | ℃ | single/lt | < 50℃ |
| bms_diffv | BMS | 单体压差 | diff_v | V | single/lte | ≤ 0.05V |
| mppt_online | MPPT | 链路在线 | — | — | none | 仅在线 |
| mppt_pvv | MPPT | 光伏电压 | pv_v | V | range | 20 ~ 120 V |
| mppt_chargei | MPPT | 充电电流 | charge_i | A | single/gt | > 0A |
| dcdc_online | DCDC | 链路在线 | — | — | none | 仅在线 |
| dcdc_outv | DCDC | 输出电压 | out_v | V | range | 40 ~ 60 V |
| dcdc_temp | DCDC | 散热温度 | temp | ℃ | single/lt | < 45℃ |

### 4.2 字段结构

```
CheckItemDef {
  id: string        // 固定标识，持久化合并键；内置项固定，自定义项生成 'ck_'+时间戳（碰撞加尾 x）
  dev: 'BMS'|'MPPT'|'DCDC'|string  // 显示用文本（自定义项任意）；判定取其小写前缀拼 fid
  name: string      // 项目显示名
  fid: string       // 数据字段 id（小写），none 模式为空串
  unit: string      // ''/'V'/'%'/'℃'/'A'/自定义，用于徽章与弹窗后缀
  mode: 'none'|'single'|'range'
  cmp: 'gt'|'lt'|'gte'|'lte'  // 仅 single 有效
  min, max: number|null       // 仅 range 有效
  val: number|null            // 仅 single 有效
  en: bool          // 启用开关
  custom: bool      // 自定义项标记：true=可删除/可编辑元信息；内置项无此字段(或 false)
}
```

> **关键约定（P0 教训）**：`fid` 与 DOM/bridge 的字段 id **全链路小写**（如 `bms-pack_v`）；`dev` 大写仅作显示。Qt 落地时统一约定：属性 id 一律小写，展示文本另行保存。自定义项新增时 UI 需校验 fid 指向的字段真实存在（Qt 可查询监控字段注册表给出下拉/自动补全，原型为手填+占位提示）。

### 4.3 持久化与加载合并（JS ≈ L1853-1868）

- 存储 key：`gcs_checkcfg`；值为**全量条目数组**（内置项改动 + 自定义项，含 name/dev/fid/unit/custom 全字段）。
- 加载合并策略（loadCheckCfg）：
  1. 以代码内 `CHECK_DEFS` 为基底逐 id 用存储值覆盖（新版本增删内置项自动兼容；取不到的字段回落默认值）；
  2. 存储中**不在 CHECK_DEFS 中的条目视为自定义项**，补默认字段后追加列表尾部（`custom:true`）。
- id 规则：内置项永不改名（改名=老用户丢配置）；自定义项 id 由时间戳生成，用户不可见。
- Qt 落地建议改用 `QSettings`（键 `check/<id>/<field>`）并加 `schemaVersion`，避免旧数据覆盖新版默认值的语义漂移（原型 P3 遗留项）。

### 4.4 判定逻辑 `ckEval`（JS ≈ L1868）

```
if (!en)                → skip（不入统计，当前值列显示「已停用」）
if (mode==='none')      → pass，值列固定「在线」
v = 实时取值(dev+fid)
if v 无效(NaN)          → fail，值列「—」     // 数据源缺失也是失败！
mode==='range'          → ok = (v > min && v < max)   // 开区间
mode==='single'         → ok = gt:v>x / lt:v<x / gte:v>=x / lte:v<=x
```

### 4.5 值格式化 `ckFmt`

`unit=='%'` 取整；`unit=='V' 且 |v|<1` 两位小数；其余一位小数 + 单位直连（如 `367.7V`、`85%`、`0.03V`、`46.3℃`、`6.4A`）。

## 五、参数编辑与动态增删

复用全局模态（宽 420px，头部标题 + × 关闭，Esc 可关）。

### 5.1 编辑弹窗（内置项与自定义项共用）

标题：内置项 `自检参数 · {dev} {name}`；自定义项编辑同格式；新增为 `新增自检项`。主体为 set-group 分组行（label 左控件右）：

| 控件 | 类型 | 联动行为 |
|---|---|---|
| 启用此自检项 | checkbox | 无联动，控制该行 en |
| **项目名称** | text（≤20 字） | **仅自定义项显示** |
| **设备标识** | text（≤10 字） | **仅自定义项显示**；占位提示「如：DCDC（判定取其小写前缀）」 |
| **数据字段 fid** | text（≤24 字） | **仅自定义项显示**；占位提示「监控页字段 id，如 out_i / in_v」 |
| **单位** | text（≤8 字） | **仅自定义项显示**；可留空 |
| 检查方式 | select：无(仅在线)/单阈值/范围 | 切换时下面各行显隐 |
| 比较符 | select：大于 > / 小于 < / 大于等于 ≥ / 小于等于 ≤ | 仅 single 显示 |
| 阈值数值 | number 输入 + 单位后缀（12px `--text-2`） | 仅 single 显示 |
| 下限 / 上限 | 两行 number 输入 + 单位后缀 | 仅 range 显示 |
| 取消(.btn ghost) / 保存(.btn) | footer 右对齐 | 取消直接关闭不改任何值 |

**校验规则（保存时，不通过则红色错误 toast 且弹窗不关闭、焦点回出错框）**：
1. single：阈值数值必填且为有效数字 → 否则「请输入有效的阈值数值」。
2. range：下限上限均必填 → 否则「请输入有效的下限和上限」；**min >= max 拒绝** → 「下限必须小于上限」。
3. 自定义项元信息必填：名称空 →「请输入项目名称」；设备空 →「请输入设备标识」；**mode≠none 时 fid 必填** →「请输入数据字段 fid」。
4. 按模式只写相关字段：切到 single 只更新 val（保留原 min/max），切到 range 只更新 min/max —— 防止隐藏字段被写 0 污染。
5. `mode:'none'` 无需数值与 fid 校验。

### 5.2 新增自定义项（`#ckAdd`，JS ≈ L1993）

- 点击头部「＋ 新增自检项」→ 打开空白自定义弹窗（默认 single/gt/val 0）。
- 保存：id=`ck_+时间戳`（碰撞尾缀加 x 保证唯一），`custom:true`，追加列表尾部 → 整页重跑 → toast「自检项已添加」。
- 新项立即参与：三态渲染、10s 自动刷新、就绪度统计与明细。

### 5.3 删除自定义项（JS ≈ L1981-1990）

- 仅 `custom:true` 的行渲染垃圾桶按钮；内置项无删除入口。
- 点击：从存储移除该条 → 整页重跑 → toast「已删除自检项：{name}」。
- **内置 11 项不可删**（工程基线保障：出厂检查集始终存在）。

### 5.4 内置项保存成功

写持久化 → 立即整页重跑 runCheck → 关闭弹窗 → 成功 toast「自检参数已保存」。

## 六、动态行为与就绪度聚合

### 6.1 定时刷新
`Timer(10000ms)` 周期执行 runCheck；每次从持久化重新读取配置（用户编辑即时生效于下一轮）。手动点「重新自检」立即执行一轮。

### 6.2 渲染流程 `runCheck`（JS ≈ L1888）
清空列表 → 逐 def 判定（顺序=内置 11 项 + 自定义项按添加序）→ push 启用项进 checkState → 三态渲染（自定义项附垃圾桶按钮）→ 更新头部结果胶囊（启用项全过=「全部通过」，否则「有项未通过」）→ updateReadiness()。

### 6.3 就绪度分级 `updateReadiness`（JS ≈ L1955）

仅统计 checkState（**已启用项**，skip 不入列表）中 fail 数：

| fail 数 | 胶囊态 | 文案 |
|---|---|---|
| 尚未自检 | `.none` 灰 | 待自检 |
| 0 | `.ready` 绿 | ✓ 就绪可飞 |
| 1 | `.warn` 黄 | ⚠ 起飞受限 |
| ≥2 | `.fail` 红 | ✗ 不可起飞 |

展示位置：监控页顶部横幅右侧 `#readinessBtn`（HTML ≈ L947），点击弹出 `readPop` 明细浮层——逐条「✓/✗ 设备 · 项目名 + 当前值」。就绪度胶囊在全局任意页面可见（属于顶栏横幅区域），明细浮层点击外部/Esc 关闭。

## 七、Qt(QML) 落地实现要点

### 7.1 组件选型

| UI 元素 | QML 实现 |
|---|---|
| check-panel / check-head | ColumnLayout + Rectangle（token 化配色，见 3.4 表） |
| 检查列表 | `ListView` + model:`ListModel`(由 C++/JS 注入，内置 11 项+自定义项) 或 Repeater+ColumnLayout（量级推荐后者，免滚动手感调优） |
| 检查行 delegate | RowLayout：状态圈(Rectangle+Text)、设备 Text、名称 Item(AppText+可选“已停用”Chip)、阈值 Chip、值 Text(Mono)、ToolButton(齿轮 Icon)、阻塞 Chip；三态注入 `delegate.state='pass/fail/skip'` 配合 States/属性绑定 |
| 编辑弹窗 | Dialog(modal) 内 GroupBox 行布局；ComboBox×2 + TextField(range/single)；单位后缀 Label；自定义项模式追加 4 个元信息 TextField（name/dev/fid/unit），fid 建议结合监控字段注册表做 ComboBox/自动补全 |
| 行操作按钮 | 齿轮 ToolButton（全部行）+ 垃圾桶 ToolButton（`custom==true` 才 visible），hover 红色态 |
| 新增按钮 | 头部 Button（ghost 样式）→ 打开空白编辑 Dialog → 保存时 engine.addItem(def) |
| toast | TrayTip/自定义 Rectangle 队列动画（ok 绿 / err 红），3000ms 自动退场 |
| 定时刷新 | Timer{ interval:10000; repeat:true; onTriggered: checkEngine.runAll() } |
| 就绪度明细弹层 | Popup + ColumnLayout 逐行；closePolicy: CloseOnPressOutside |

### 7.2 引擎放 C++ 还是 QML

建议 **C++（CheckEngine QObject）**：
- `Q_PROPERTY(QVariantList items)` + `Q_INVOKABLE void runAll()`；
- 动态增删接口：`Q_INVOKABLE QString addItem(QVariantMap def)`（生成唯一 id、写持久化、refresh 模型，返回新 id）与 `Q_INVOKABLE bool removeItem(const QString& id)`（仅 custom 项可删，内部断言保护）；模型变更发 `itemsChanged()`；
- 数据对接与监控桥一致：`double value(const QString& devId, const QString& fid)`（内部走 bridge 实时值；NaN→fail“—”）；
- `QSettings` 持久化 + schemaVersion 迁移（内置项逐 id 合并 + 未知 id 追加为自定义项，与原型 loadCheckCfg 同策略）；
- 发射 `checkFinished(int fails)` → QML 绑定就绪度胶囊。
UI 纯逻辑少，也可以纯 QML 实现 engine js 文件；但考虑后续接入真实信号总线，C++ 引擎更稳。

### 7.3 数据源接线

- 取值同监控页桥：`bridge.value(devLower(fid), fid)`，**id 一律小写**（见 4.2 关键约定，原型曾因大小写不一致导致整页失效）。
- 数据缺失（无效值/QByteArray 空）必须判 fail 显示「—」，不允许静默通过。
- 模拟模式下可与监控页共用同一份模拟数据驱动器，保证两页数字一致。

### 7.4 校验落地细节

- TextField 设置 `validator: DoubleValidator{ notation:"Standard" }` 且再做空串判断（validator 放行空输入）。
- min>=max 校验放在保存槽函数内，与原型规则逐字一致（提示文案也保持相同中文）。
- 保存只写当前 mode 相关字段（C++ 结构体内保持其它字段原值）。

### 7.5 就绪度跨页联动

CheckEngine 单例暴露 `readyLevel`(int 0-3) + `failCount`(int)；监控页横幅胶囊 `visible: readinessVisible && checkedOnce`，颜色/文案按下表绑定；明细浮层读取 CheckModel。

## 八、验收测试清单（落地对照原型逐条）

1. 列表 11 行结构与示例徽章文案（`360~380V`、`>30%`、`<50℃`、`≤0.05V`…）逐一比对。
2. 真实数据：全部数值项当前值来自实时桥，正常工况 ≥8 项通过。
3. 数据缺失：断开某模拟数据源 → 对应项 fail 显示「—」+ 阻塞起飞。
4. 头部结果胶囊随任一启用项失败变红「有项未通过」。
5. 停用某项 → 行灰色 –、「已停用」角标、阈值徽章消失、值列「已停用」；就绪度明细不再出现该项；重新启用恢复。
6. 清空单阈值保存 → 红色 toast「请输入有效的阈值数值」，未保存未关窗。
7. 范围颠倒(min≥max) → 红色 toast「下限必须小于上限」，未保存。
8. 切换检查方式三档联动显隐正确；single↔range 切换互不污染另一组字段。
9. 比较符四选一生效（含等号边界：构造恰好 = 阈值的数据验证 gte/lte）。
10. 取消编辑不落盘；重启应用后参数还原为上次保存值（持久化合并策略）。
11. 10s 自动重跑 & 手动「重新自检」即时执行；期间编辑的参数下一轮生效。
12. 就绪度四级（待自检/✓/⚠/✗）触发条件各验一次；Esc 与点击外部关闭明细浮层。
13. 深/浅主题切换后三态配色仍符合 token 表。
14. 动态新增：点「＋ 新增自检项」→ 弹窗含 4 行元信息；空名称/空设备保存被拦截（红 toast、不关窗、焦点回出错框）；正确填写后列表尾部新增行、toast「自检项已添加」、重启应用后仍在。
15. 新项全联动：新项立即参与 10s 刷新与就绪度统计（构造必失败项→胶囊降级、明细多一条 fail）。
16. 删除：仅自定义项有垃圾桶按钮（内置 11 项无）；点击删除→行消失、toast、持久化同步移除；内置项删除入口不存在。
17. 编辑回显：自定义项齿轮弹窗元信息（名称/设备/fid/单位）与已保存值逐字一致；内置项弹窗无元信息行。
