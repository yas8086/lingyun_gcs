# 灵云01 地面站 · 全面开发计划

> **适用对象：** 灵云地面站（Qt 桌面端）的规范化、全面开发。
> **执行方式：** 建议使用 `subagent-driven-development` 或 `executing-plans` 逐任务执行；任务用 `- [ ]` 勾选跟踪。
> **基线：** 依据《地面站对接协议》（最新树莓派文档）与《落地开发决策清单》（#1-36 已拍板）。

**Goal:** 交付一套架构合理、代码规范、功能完整、UI 与 HTML 原型高度一致（布局/色彩/交互/响应式）的灵云01桌面地面站系统。

**Architecture:** 三层架构 —— C++ 后端核心（串口/协议/数据/告警/存储）+ QML 前端（Qt Quick 复刻原型视觉）+ 桥接层（context property 暴露后端能力）。前端与后端通过 `TelemetryBridge` 解耦，后端可独立测试。

**Tech Stack:** Qt 6.10 / C++17 / CMake / Qt Quick + Qt Quick Controls + QtCharts / QSerialPort / Qt Test。

## 需求分析

### 功能需求（已拍板，源自决策清单）
| 域 | 需求 |
|----|------|
| 数据接入 | 串口 115200/8N1，`AA55 JSON \n` 帧；BMS/备用BMS/MPPT/DCDC/LoRa 解包；null 容错 |
| 监控 | 五设备卡片实时值、链路/在线灯、实时曲线（QtCharts）、飞艇横幅 |
| 告警 | 规则引擎（Fault/Threshold）+ 故障码接入、来源标注、声音（默认关）、确认机制（未确认计数）、环形上限 |
| 交互安全 | 紧急操作（动作选择+滑动确认）、整机就绪度聚合（11 项自检） |
| 温度 | LoRa 温度/压力节点展示、探头 pid 映射、历史 CSV 导出 |
| 导出 | 快照 JSON、报告 CSV、录制 CSV、温度 CSV |
| 偏好 | JSON 持久化：温度单位/告警声音/曲线窗口；模块可见性 |
| 导航 | 左侧导航：监控/自检/地图/飞控/图示/设置（非监控页按原型补全） |

### 非功能需求
- 响应式：宽屏/窄屏自适应，最小 960×640 可用。
- 性能：5Hz 数据下 UI 流畅，曲线滚动 120 点无卡顿。
- 可维护：分层清晰、模块单职责、接口稳定。
- 质量：单元测试覆盖数据层与核心逻辑；集成测试覆盖端到端。

## 系统架构与模块划分

```
┌──────────────────────────── QML 前端 (lingyun_gcs_qml) ────────────────────────────┐
│ nav(60) │ topbar(品牌/在线灯/就绪度/紧急操作) │ content(监控/自检/地图/飞控/图示/设置) │
│         │         QtCharts 曲线 · 设备卡 · 告警 · 日志 · 温度          │
└──────────────▲──────────────────────────────────────────────────────────┘
               │ context property: bridge
┌──────────────┴──────────────── C++ 桥接层 ──────────────────────────────┐
│ TelemetryBridge(Q_INVOKABLE value/online/readinessState/串口控制)        │
└──────────────▲──────────────────────────────────────────────────────────┘
               │ 信号槽
┌──────────────┴──────────────── C++ 后端核心 ────────────────────────────┐
│ comms: serial_manager · frame_parser · json_decoder                     │
│ model: telemetry_data                                                   │
│ core : data_bus · alarm_engine · config_manager · recorder · replay     │
└──────────────────────────────────────────────────────────────────────────┘
```

- **comms/**：串口、帧定界、JSON 解码（纯逻辑，可脱离 UI 测试）。
- **model/**：遥测数据结构（纯数据）。
- **core/**：数据总线、告警规则引擎、配置、录制/回放（纯逻辑，可测试）。
- **qmlbridge/**：C++→QML 桥接（薄层，只做类型转换与转发）。
- **qml/**：QML 前端（视觉/交互/响应式）。
- **tests/**：Qt Test 单元测试；未来含集成测试。
