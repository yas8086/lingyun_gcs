## Task 4: 危险操作两步确认

**Files:**
- Modify: `docs/ui-prototype/airship-gcs-prototype.html`

**Interfaces:**
- 新增通用 `function confirmTwice(btn, label, action)`：第一次点击按钮变确认态（红色 + "确认label？"+ 3s 倒计时自动复位），第二次点击执行 `action`。
- 应用于「清空告警」（`data-f="clear"`）、「恢复默认」（`#mpReset`、`#resetSet`）。「紧急操作」已有滑动确认，保持不动。

**Step 1: confirmTwice 函数与样式**

CSS 追加：

```css
  /* 危险操作确认态 */
  .btn.confirming,.ctl-btn.confirming{background:var(--err)!important;color:#fff!important;border-color:transparent!important}
```

JS 加：

```javascript
function confirmTwice(btn,label,action){
  if(btn.dataset.armed==='1'){btn.dataset.armed='';btn.classList.remove('confirming');btn.textContent=label;action();return;}
  btn.dataset.armed='1';btn.classList.add('confirming');const orig=label;let n=3;
  btn.textContent='确认'+label+'？('+n+'s)';
  btn._ct=setInterval(()=>{n--;if(n<=0){clearInterval(btn._ct);btn.dataset.armed='';btn.classList.remove('confirming');btn.textContent=orig;}else btn.textContent='确认'+label+'？('+n+'s)';},1000);
}
```

**Step 2: 挂接**

- 清空告警按钮：原 `data-f="clear"` 的点击逻辑改为 `confirmTwice(this,'清空',()=>{ /*原清空逻辑*/ })`。
- `#mpReset`（探头映射恢复默认）、`#resetSet`（设置恢复默认）：点击逻辑改为 `confirmTwice(this,'恢复默认',()=>{ /*原逻辑*/ })`。

> 需先阅读这三处现有绑定代码，把其 handler 体包进 `action` 回调，保持行为不变。

**Step 3: 浏览器验证**

点"清空"按钮变红并倒计时，3s 自动复位；倒计时内再点才执行清空并 toast。
