# 原型全部功能落地 Qt 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 `docs/ui-prototype/airship-gcs-prototype.html`（原型）中已确认的全部进阶功能，逐一落地到 Qt6 实际地面站工程（`src/`），替换当前简易版界面，使桌面地面站与原型功能对齐。

**Architecture:** 沿用现有分层（Comms → Model → Core → UI）。UI 层从单一仪表盘重构为**导航 + 多视图**结构（监控/自检/地图/飞控/图示/设置，QStackedWidget 切换）；各功能视图为独立 QWidget，订阅 `DataBus::telemetryReady` 或独立的 `AlarmEngine`/规则信号刷新。协议与模型先行扩展（温度/探头、电源拓扑节点），UI 消费同一 `TelemetryData`。

**Tech Stack:** Qt6 (Core/Gui/Widgets/SerialPort/Test) + QCustomPlot + CMake + C++17。配置用 QSettings，持久化（告警历史/探头映射/主题）用 QSettings 或 JSON 文件。

## Global Constraints

- C++17 标准；Qt 6（需 SerialPort、Widgets、Test）。
- 协议遵循《地面站对接协议》：帧 = `0xAA 0x55` + 单行 JSON + `\n`，115200 8N1，5Hz；离线设备键不出现。
- 唯一第三方依赖：QCustomPlot（内部自用按 GPL）。
- 地面站本地不装 ROS2，不实现控制下发。
- 所有代码注释用中文；所有可见文案用中文。
- 只修改 `src/`、`tests/`、`tools/`、`CMakeLists.txt`、`docs/机载计算机对接文档/地面站对接协议.md`；**不改 HTML 原型**（原型为 UI 权威参考）。
- 新状态须支持深浅主题（沿用现有 QSS / 用 CSS 变量思路在 Qt 中以调色板+QSS 实现）。
- 跨平台：不引入平台相关 API（QSerialPortInfo 兼容双平台）。
- 分支：`feat/ground-station`；每任务独立 commit。
- 验证：`cmake -S . -B build && cmake --build build -j && ctest --test-dir build --output-on-failure`；UI 用 `QT_QPA_PLATFORM=offscreen` 冒烟 + `tools/serial_simulator.py` 端到端。

```cpp
#include "ui/nav_bar.h"
#include <QVBoxLayout>
#include <QToolButton>
#include <QButtonGroup>

namespace lgs {
NavBar::NavBar(QWidget *parent) : QWidget(parent) {
    auto *lay = new QVBoxLayout(this);
    lay->setContentsMargins(8, 8, 8, 8);
    lay->setSpacing(4);
    group_ = new QButtonGroup(this);
    group_->setExclusive(true);
    setObjectName("navBar");
}
void NavBar::addView(const QString &id, const QString &label) {
    auto *btn = new QToolButton(this);
    btn->setCheckable(true);
    btn->setText(label);
    btn->setToolButtonStyle(Qt::ToolButtonTextBesideIcon);
    btn->setProperty("navId", id);
    btn->setSizePolicy(QSizePolicy::Expanding, QSizePolicy::Fixed);
    group_->addButton(btn);
    layout()->addWidget(btn);
    connect(btn, &QToolButton::clicked, this, [this, id]{ emit viewChanged(id); });
    if (group_->buttons().size() == 1)
        btn->setChecked(true);
}
} // namespace lgs
```

```cpp
namespace lgs {
double convertTemp(double c, UnitTemp to) {
    return to == UnitTemp::F ? c * 9.0 / 5.0 + 32.0 : c;
}
double convertPower(double w, UnitPower to) {
    return to == UnitPower::kW ? w / 1000.0 : w;
}

} // namespace lgs
```
