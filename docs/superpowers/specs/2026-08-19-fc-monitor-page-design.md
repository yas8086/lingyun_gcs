# 灵云01 地面站 · 飞控监控页设计（B 数据卡网格 · 只监控）

> 日期：2026-08-19
> 状态：设计已与用户确认，进入实现
> 目标：在 `airship-gcs-prototype.html` 中，将「飞控」页占位（`#view-flight`，L1003-1013）替换为完整的**飞控监控页**，视觉与交互对齐地面站现有简洁商用风。

---

## 一、定位与约束

- **只监控，不控制**：页面不含任何指令按钮（起飞/降落/急停等）、不含模式切换、不含参数编辑、不含操作树。所有元素仅做数据展示。
- **骨架**：方案 B「数据卡网格」，与监控页/摄像头页视觉语言统一。
- **模块**（用户已确认）：姿态仪表、导航数据、电机状态、链路与定位、飞行模式（只读）。
- **不含** HUD 视频（机载相机已由独立摄像头页承载）。

> **集成变更（2026-08-19）**：飞控与地图合并为一个页面。采用「**地图为主 + 飞控浮层**」（QGC 飞行视图风格）。保留「飞控」导航入口，删除「地图」导航入口与独立 `#view-map` 页面。地图作为背景画布，飞控数据以左侧浮层列展示。

## 二、页面结构（飞控+地图集成后）

```
fc-panel（占满 #view-flight）
├── 顶栏 fc-bar：标题「飞控」+ 飞行模式只读徽章 + 链路/GPS 状态
├── 主体 fc-fly（地图为主，相对定位）
│   ├── 地图画布 fc-map：网格 + 比例尺 + 飞行器标记(带航向) + 航迹线
│   ├── 左侧浮层列 fc-layer（258px，自上而下叠放）：
│   │   ├── 姿态仪表浮层（人工地平仪 168px，只读）
│   │   ├── 导航数据浮层（高度/地速/航向/升降率/经纬度）
│   │   ├── 飞行模式浮层（只读列表，当前高亮）
│   │   ├── 链路与定位浮层（数传/遥控/GPS/数据率/告警）
│   │   └── 电机状态折叠浮层（收起/展开，10 台转速+温度）
│   └── 右上遥测角标 fc-tlm：高度/位置/航向/地速/舱内气压
└── 底栏 fc-foot：时间 / 数据率 / 链路 / GPS / 告警
```

## 三、模块详细

### 1. 姿态仪表（左列大卡，视觉核心）
- 圆形人工地平仪（SVG）：天空/地面双色球面 + 俯仰格线 + 横滚三角指针 + 航向刻度。
- 仪表下方数字：`俯仰 +3.2° · 横滚 -1.4° · 航向 127°`。
- 状态角标：正常（绿）/ 数据丢失（灰）。

### 2. 导航数据卡
| 项 | 单位 |
|---|---|
| 相对高度 | m |
| 地速 | m/s |
| 航向 | ° |
| 升降率 | m/s |
| 经度 / 纬度 | ° |

### 3. 飞行模式卡（只读）
- 模式列表：手动 / 定高 / 悬停 / 返航 / 任务。
- 当前模式高亮（主色底），其余灰态；**整卡不可点击**。
- 附加：任务序号/阶段只读文本（无任务时显示「—」）。

### 4. 电机状态卡
- 分组：推进电机（4 台）+ 上升电机（6 台）。
- 每台：名称 + 转速进度条（归一化到上限）+ 转速值 + 温度值。
- 全部展示（不折叠），卡内滚动；温度 > 阈值显示告警色。

### 5. 链路与定位卡
| 项 | 说明 |
|---|---|
| 数传 | 质量 %（绿/黄/红） |
| 遥控 | 在线状态 |
| GPS | 卫星颗数 |
| 数据率 | Hz |
| 告警 | 当前告警计数（0 绿 / >0 黄） |

## 四、视觉规范（沿用现有 CSS 变量）

- 卡片：`var(--card)` 底 + `var(--line)` 边框 + 12px 圆角；卡头 12px/700 `--text-2` + 图标 + 状态角标（`.tag.g/.w/.r`）。
- 数值：等宽字体 `--mono`，主值 15-19px/700 `--text`，单位 11px `--text-2`。
- 语义色：绿 `--ok` 正常 / 黄 `--warn` 告警 / 红 `--err` 故障 / 灰 `--text-2` 离线。
- 无任何控制态（无 hover 反馈、无按下态、无 disabled 样式需求）。

## 五、动态行为（模拟数据）

- 定时（1s）刷新：姿态（俯仰/横滚/航向小幅波动）、导航（高度/速度漂移）、电机（转速抖动 + 温度缓变）、链路（质量/数据率抖动）、模式（保持当前，不切换）。
- 供演示：可将上升电机温度周期抬升至 > 阈值触发告警色（可复用于后续 Qt 落地告警联调）。

## 六、落地注意（Qt 后续）

- 本页为纯展示，Qt 落地时数据走 `bridge.value(device,key)`（att / nav / motor / link），无需回传控制指令。
- 姿态仪表建议 Qt 用 Canvas 绘制（与电源链路同路线）或 QtCharts/自定义 QML。
